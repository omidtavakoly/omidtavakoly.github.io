# Portfolio — Omidreza Tavakoly

Static, no-build 4-page site: `index.html`, `projects.html`, `experience.html`, `contact.html`, sharing `assets/styles.css` and `assets/theme.js`.

## Deploy with GitHub Pages

1. Push this folder as the root of a repo (e.g. `omidtavakoly/portfolio` or `omidtavakoly.github.io` for a root domain).
2. Repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, folder: `/ (root)`.
3. Site goes live at `https://<username>.github.io/<repo>/` (or `https://<username>.github.io/` if the repo is named `<username>.github.io`).

No build step, no dependencies — just static files.
